About LIBRA Digital Library Portal

An enterprise-grade academic e-book circulation and digital catalog management platform designed for modern collegiate libraries.

Atomicity & Integrity

Built with Django's atomic transactions (select_for_update) to prevent race conditions in copy reservations and returns.

Configurable Fines

Transparent 14-day borrowing cycles with server-evaluated fine assessments (default ₹5.00/day) backed by an interactive real-time calculator.

Staff & Student Portals

Role-segregated experiences: students track personal loans and requests; librarians approve checkouts with live Chart.js KPI analytics.

Technical Architecture & Specifications

Backend & Database
  • Python 3.11+ / Django 5.x robust MTV architecture
  • SQLite (db.sqlite3) lightweight embedded relational persistence
  • Django Authentication SHA-256 PBKDF2 password hashing & token resets
  • Gunicorn WSGI production process manager
Frontend & Deployment
  • Bootstrap 5.3 + Custom CSS responsive editorial library aesthetic
  • Vanilla JavaScript (ES6+) client-side instant search & fine calculators
  • Chart.js librarian inventory & circulation analytics
  • WhiteNoise 6.8+ & Render Cloud static compression & HTTPS deployment
